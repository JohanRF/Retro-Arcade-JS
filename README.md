# Retro Arcade JS

Plataforma de juegos arcade clásicos de los 90, jugables directo en el navegador. Empecé con Snake, con Pong y Tetris en camino.

## 🔗 Demo en vivo
[johanrf.github.io/Retro-Arcade-JS](https://johanrf.github.io/Retro-Arcade-JS/)

## 📋 Qué incluye
- **Snake** — juego completo con lógica de colisiones, puntaje y controles por teclado
- Pong y Tetris — en desarrollo

## 🛠️ Tecnologías
- JavaScript (clases, estructuras de control como `do-while`)
- HTML5 Canvas (o el elemento que uses para renderizar — ajusta si es distinto)
- CSS3

## 🚀 Cómo correrlo localmente
\`\`\`bash
git clone https://github.com/JohanRF/Retro-Arcade-JS.git
cd Retro-Arcade-JS
# abrir index.html directamente en el navegador
\`\`\`
